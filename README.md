# 凡人修仙传·类比检索引擎（xiuxian skill）

> 任何事情，去《凡人修仙传》中找可类比的人物、事件、法宝、功法、境界、地点。

## 这是什么

把忘语《凡人修仙传》全本 **730 万字 / 2,457 章节**拆成可检索的知识库，配上 126 个核心要素（人物/法宝/功法/境界等），遇到任何问题就去原文里找最贴的类比。

不是简单关键词搜索——是**要素 + 场景**联合匹配。

| - 境界 | 11 | 炼气 → 真仙 → 金仙 |

## 评分算法

```
score = 关键词密度 × 1.0 + 要素命中数 × 5.0
```

要素命中权重 ×5（更接近"真实相关性"），关键词密度 ×1（字面相关）。

## 不做什么

- ❌ 不编造原文（只引用真实片段）
- ❌ 不强行类比（无相关章节时明说）
- ❌ 不把修仙概念当万能解释（类比是辅助，不是替代）

## 局限

- 中文 2-gram 切分对问句（"如何..."）支持弱，靠要素命中补偿
- v2 计划：jieba 分词 + 修仙同义词扩展 + 章节摘要索引
